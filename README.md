## 🚀 快速开始 | Quick Start

```bash
git clone https://github.com/Windyhhh/Industrial-Projects.git
cd Industrial-Projects

# 各子项目独立运行，查看对应子项目 README
# 示例：运行设备故障检测
cd device-fault-detection
pip install -r requirements.txt
python main.py --data data/sample.csv
```
